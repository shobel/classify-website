User guides

Step-by-step instructions for installing, managing, and troubleshooting Classify at your school.

Installing for the first time

Classify installs on one computer at your school — typically the administrator's machine. Teachers don't install anything; they access it through their browser.

Which computer? Install on a machine that stays on and connected to the school network during the school day. Teachers connect to it from their own devices.

1
Download the installer

Get the latest version from the Classify website. On Mac, download the .dmg file matching your chip — arm64 for Apple Silicon (M1/M2/M3/M4), or the standard .dmg for Intel.

2
Open the DMG and drag to Applications

Double-click the downloaded .dmg file, then drag the Classify icon into the Applications folder shortcut in the window.

3
Open Classify

Find Classify in your Applications folder and double-click it. The first launch takes a few seconds while the background server starts.

4
Enter your activation code

You'll be prompted to enter the activation code you received when purchasing Classify. Enter it and click Activate.

5
Create your admin account

On first run, you'll be asked to set up the admin account — choose a username and password. This becomes the primary administrator account.

Activating your license

Each Classify license is tied to an activation code. You enter it once and the app is permanently unlocked on that machine.

1
Find your activation code

Your code was sent by email when you purchased Classify. It looks like a short string of letters and numbers.

2
Enter it in the activation screen

When you first open Classify, you'll see the activation screen. Type or paste your code and click Activate. Classify verifies the code with our server — an internet connection is required for this step only.

3
Done — the app works offline from here

Once activated, Classify runs entirely on your school's network. No internet connection is needed for day-to-day use.

Each code is single-use. If you need to move to a new computer, contact us for a transfer — don't re-enter the same code on a new machine without reaching out first.

Installing a new version

Updating Classify is straightforward. Your data is never touched during an update — it lives in a separate location from the app itself.

1
Download the new version

Classify will show an update notification when a new version is available. Download the new .dmg from the link provided.

2
Drag the new version to Applications

Open the DMG and drag Classify to Applications. macOS will ask if you want to replace the existing version — click Replace.

3
Open Classify

Open the app as normal. Classify detects that the version has changed and automatically restarts its background server with the new version. This takes a few seconds.

Teachers stay connected. The background server keeps running while the Electron window is closed, so teachers in their browsers aren't interrupted during normal use. The server only restarts when you open the new version — plan updates for a quiet moment.

Giving teachers access

Teachers open Classify in any browser — no app to install. They just need the address of your school's Classify server and an account.

1
Find your school network address

In Classify, go to School config. Your school network URL is shown there — it looks like http://192.168.x.x:5001. This is the address teachers type into their browser.

2
Make sure teachers are on the same network

Teachers must be connected to the same school Wi-Fi or wired network as the computer running Classify. The address won't work from home or over a different network.

3
Create an account for each teacher

Go to Users in the sidebar and click Add user. Generate an invite code and share it with the teacher. They visit the setup page, enter the code, and choose their own username and password.

4
Share the address

Send teachers the network URL. They bookmark it in their browser and use it to sign in from any device on the school network.

Screenshot — School config screen showing the network URL Highlight the URL field teachers should bookmark

The host computer must be on. If the computer running Classify is off or asleep, teachers won't be able to connect. Make sure it's set to never sleep while plugged in.

Adding & removing users

Only admins can manage user accounts. Teachers and assistants are added via invite codes — there's no self-registration.

1
Go to Users in the sidebar

This screen is only visible to admin accounts.

2
Click "Add user"

Choose whether the new user should have admin privileges or teacher access. Click Generate invite code.

3
Share the code

Copy the code or use the email link. The invite expires in 7 days. The teacher goes to the Classify setup page at your school's network address and enters the code to create their account.

To remove a user:

1
Find the user in the Users screen

Click Remove next to their name. They are immediately signed out and can no longer access Classify.

To change a user's role:

1
Click "Make admin" or "Make teacher"

Next to any user (other than yourself), you can toggle their role between Teacher and Admin without creating a new account.

Starting a new school year

At the start of each year, Classify promotes every student up one grade automatically. Your previous year's data stays intact and accessible.

1
Click the ↗ button next to "School years" in the sidebar

This creates the next school year and promotes all students — Kindergarten moves to 1st grade, 1st to 2nd, and so on. 8th graders are not promoted (they graduate). A new empty Kindergarten is created for incoming students.

2
Review and adjust

All student data, notes, and history carry forward. Class placements from the previous year are cleared so you can run a fresh placement for each grade.

3
Add new Kindergarteners

Import or manually add incoming students to the new Kindergarten grade.

Previous school years are never deleted — you can switch between them at any time using the sidebar.

App won't open

There are two common reasons Classify might not open on a Mac.

macOS says it "cannot verify" the app

This is a Gatekeeper warning. It means you downloaded an older version that wasn't notarized, or you're on a newer macOS that's being extra cautious.

1
Make sure you have the latest version

Download the current release from the Classify website. Older releases may not be notarized.

2
If the warning still appears: right-click → Open

Right-click (or Control-click) the Classify app in your Applications folder and choose Open. Then click Open in the dialog. You only need to do this once.

3
Or: System Settings → Privacy & Security

Scroll down to the security section and click Open Anyway next to the Classify entry.

The app opens but shows an error about the server

1
Check if port 5001 is in use

Another app may be using port 5001. Quit any other local server apps and try opening Classify again.

2
Quit and reopen

Quit Classify completely (Classify menu → Quit) and reopen it. The server will restart fresh.

Forgot admin password

If you've forgotten your admin password, there's an emergency recovery page accessible only from the computer running Classify.

This only works from the host computer. The recovery page is blocked from all other devices on the network — it can only be accessed from the machine running Classify.

1
On the Classify host computer, open a browser

Go to http://127.0.0.1:5001/admin-recovery

2
Select your admin account and set a new password

Choose the admin account from the list and enter a new password (at least 6 characters). Click Reset password.

3
Sign in with the new password

Return to Classify and sign in normally.

Moving to a new computer

If you're replacing the machine that runs Classify, export a backup from the old computer and import it on the new one.

1
On the old computer: export a backup

In Classify, go to School config and click Export backup. This creates a .classify file containing all your data.

2
Install Classify on the new computer

Download and install the latest version on the new machine. When you reach the activation screen, you'll see an option to restore from backup instead of entering a code.

3
Import the backup file

Click Restore from backup, select the .classify file from the old computer, and Classify will restore all your data. Your activation transfers with the backup.

4
Update the network URL for teachers

The new computer will have a different IP address. Share the new URL with teachers so they can update their bookmarks.

Contact us before activating on the new machine if you have any trouble with your activation code transferring.

Uninstalling completely

Dragging Classify to the Trash removes the app but leaves your data and background server intact — by design, so updates don't wipe your data. To remove everything, use the in-app uninstall option first.

This permanently deletes all data. Export a backup first if you may need the data later.

1
Export a backup (optional but recommended)

Go to School config → Export backup to save a copy of all your data before proceeding.

2
Go to Classify menu → Uninstall Classify…

In the menu bar, click Classify → Uninstall Classify…. A confirmation dialog will appear explaining what will be deleted.

3
Confirm the uninstall

Click Uninstall. Classify will stop the background server, delete all data and logs, and quit. This takes a few seconds.

4
Drag Classify to the Trash

Finally, drag the Classify app from your Applications folder to the Trash to remove the app itself. Classify is now completely uninstalled.
